# Earlier runner / pacemaker work

The legacy campaign compared isolated and grouped runners using a penalty/porosity immersed-boundary route. It was a separate code path from NGA2 and from a ghost-donor rotor example. The promotional sequence used short English titles: question → domain/conditions → Cartesian mesh → IBM → actual flow → comparison / pressure analysis. Rendering smoothness did not improve CFD resolution.

This minimal collection retains a generic pressure integration function and a transfer prompt. Original LICA source, body meshes, full campaign inputs and raw results are not bundled. Review their provenance and redistribution permission before adding them to a public repository. A new agent cannot reproduce the runner geometry from this small package alone.

`pressure_load.py` integrates outward-oriented raw triangles using stored pressure. Positive result opposes +X when integrating p*n_x. It includes every supplied face and has no exterior-union or viscous-stress correction. Never label it qualified total drag or reuse a baseline force as another frame's operand.
